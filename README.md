# tg-max-crosspost

Бот для автоматического кросспостинга из Telegram-канала в мессенджер MAX. Поддерживает текст, фото, форматирование.

## Возможности

- мониторинг Telegram-канала в реальном времени
- репост текста с сохранением форматирования
- поддержка фото и медиа
- обработка rate limits MAX API
- автоматический реконнект

## Стек

Python 3.10+, aiogram 3, aiohttp

## Запуск

```
pip install -r requirements.txt
python bot.py
```
