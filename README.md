# tg-max-crosspost

Каркас бота для переноса публикаций из Telegram-канала в MAX. В [bot.py](bot.py) есть конфигурация двух каналов и регистрация обработчика новых публикаций.

Обработчик постов, отправка текста и загрузка фото в MAX оставлены заглушками. Ограничения по частоте запросов и переподключение в этой версии не реализованы.

## Запуск

Основные зависимости перечислены в [requirements.txt](requirements.txt). Для запуска нужно реализовать функции в `bot.py`. Имена параметров, которые код читает из окружения, перечислены в самом файле. `.env.example` не соответствует конфигурации этой версии.
